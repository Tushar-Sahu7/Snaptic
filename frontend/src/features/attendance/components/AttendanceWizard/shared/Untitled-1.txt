# Button

[Previous](https://ui.shadcn.com/docs/components/radix/breadcrumb)
[Next](https://ui.shadcn.com/docs/components/radix/button-group)
Displays a button or a component that looks like a button.
[Radix UI](https://ui.shadcn.com/docs/components/radix/button)
[Base UI](https://ui.shadcn.com/docs/components/base/button)

```
import { ArrowUpIcon } from "lucide-react" import { Button } from "@/components/ui/button"
```


```
import { ArrowUpIcon } from "lucide-react" import { Button } from "@/components/ui/button"
```

## Cursor
Tailwind v4 [switched](https://tailwindcss.com/docs/upgrade-guide#buttons-use-the-default-cursor) from cursor: pointer to cursor: default for the button component.

```
cursor: pointer
```


```
cursor: default
```

If you want to keep the cursor: pointer behavior, add the following code to your CSS file:

```
cursor: pointer
```


```
Copy@layer base { button:not(:disabled), [role="button"]:not(:disabled) { cursor: pointer; } }
```


```
@layer base { button:not(:disabled), [role="button"]:not(:disabled) { cursor: pointer; } }
```
